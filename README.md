# Kiwi Launcher 0.1

Minimal Android TV launcher prototype for KIVI 50U710KB / Android TV 11.

## Included
- Dark, minimalist home screen
- Large focusable tiles designed for a TV remote
- App list and launch intents
- Shortcut to Android settings
- Declares itself as a HOME launcher

## Build
Open this folder in Android Studio (Giraffe or newer), allow Gradle sync, then Build > Build Bundle(s) / APK(s) > Build APK(s).

Target SDK is 28 to keep the first prototype compatible with older TV builds. Test on the television before setting it as the default home app. The app does not disable or remove any system components.
